# ALPYRAMID case study — assets

Each image slot on case-studies/alpyramid.html is marked `data-pending` until
its file exists; a pending slot makes no request and shows an
"Asset needed" frame.

To add a screenshot:
1. Save it here under the exact name below (.jpg — or change the
   `data-src` extension on that slot to match your file).
2. In case-studies/alpyramid.html, delete `data-pending` from that
   `<figure>`.

Use real screenshots only. No mock-ups, no recreated before/after states,
no analytics or sales dashboards (marketing had not started).
Blur any customer names, emails or phone numbers (WhatsApp and email
screenshots especially).
